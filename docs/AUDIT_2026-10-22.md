# Audit and validation notes (2026-10-22)

This patch is deliberately scoped: it does not change the DeepSC architecture or claim that 20 epochs of synthetic policy training validate semantic fidelity.

## Fixes
- Refuse empty/invalid token masks and nonpositive importance temperature; padded positions remain zero.
- Reject nonfinite VQ codewords/training vectors and invalid k-means iteration settings.
- Check allocator risk finiteness and integer symbol costs.
- Replace unconstrained ridge regression followed by coefficient clipping with projected-gradient nonnegative ridge fitting. These are not mathematically equivalent.

## Continuous verification
The GitHub Actions smoke workflow runs unit tests, 20 epochs of **synthetic** policy imitation, and a small toy QPSK simulation. Inspect Actions job output for results; presence of a workflow file does not imply a successful run.

## Outstanding real DeepSC validation
Real DeepSC integration still requires a compatible EHeum/DeepSC checkout, checkpoint, matching ordered vocabulary and Europarl data. Run fit_codebook, finetune_vq, train_importance, fit_risk_proxy, and run_semgain against disjoint splits. The external weights/data are not included in this repository. The current independent-token risk model approximates full-sentence distortion and should be tested with direct decoder CE on held-out sentences.
